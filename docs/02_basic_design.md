# FinSight Phase 1 基本設計書

## 1. 文書概要

| 項目      | 内容                                            |
| ------- | --------------------------------------------- |
| プロジェクト名 | FinSight                                      |
| 対象Phase | Phase 1 - Cloud Cost Visualizer               |
| 目的      | AWS利用料金をWebダッシュボード上で分かりやすく可視化する               |
| 対象ユーザー  | AWSを利用する中小企業・ベンチャー企業のクラウドエンジニア、AWS管理者、インフラ担当者 |

---

## 2. Phase 1の構成

Phase 1は以下の3段階で開発する。

### Phase 1-A：最低限動作するシステム

AWSの料金データを取得し、Web画面に表示できる状態を作る。

### Phase 1-B：メイン完成版

日別料金推移、サービス別料金、前日比、料金予測などを追加し、実用的なダッシュボードへ発展させる。

### Phase 1-C：運用を意識した完成版

CloudFront、HTTPS、IAM最小権限、CloudWatch、テスト、ドキュメントなどを追加し、AWS上での運用を意識した構成にする。

---

# 3. Phase 1-A 画面設計

Phase 1-Aでは、1画面のダッシュボードを作成する。

## 3.1 ヘッダー

表示内容：

* FinSight
* Cloud Cost Visualizer

---

## 3.2 コスト概要エリア

以下の3項目をカード形式で表示する。

### 今月のAWS料金

現在の月に発生しているAWS利用料金を表示する。

### 昨日のAWS料金

前日に発生したAWS利用料金を表示する。

### 前日比

昨日の料金とその前日の料金を比較し、増減率を表示する。

---

## 3.3 日別コスト推移エリア

AWS利用料金の日別推移をグラフで表示する。

目的：

* 料金が増加している日を把握する
* 月内のコスト変化を視覚的に確認する

Phase 1-Aでは基本的なグラフ表示を目標とし、詳細な分析機能はPhase 1-B以降で追加する。

---

## 3.4 サービス別コストエリア

AWSサービスごとの料金を一覧表示する。

表示例：

| AWSサービス           |  利用料金 |
| ----------------- | ----: |
| Amazon EC2        | $5.20 |
| Amazon S3         | $2.10 |
| AWS Lambda        | $0.43 |
| Amazon CloudFront | $0.18 |
| その他               | $0.12 |

利用料金の高いサービスを確認できるようにする。

# 5. Phase 1-A データの流れ

Phase 1-Aでは、以下の流れでAWS料金データを取得することを想定する。

```text
Webブラウザ
     |
     v
HTML / CSS / JavaScript
     |
     v
API Gateway
     |
     v
AWS Lambda
     |
     v
AWS Cost Explorer
```

AWS Cost Explorerから取得したデータをLambdaで必要な形式に整理し、API Gatewayを経由してWeb画面へ返す。

# 6. フロントエンド構成

Phase 1-Aでは以下の3ファイルを使用する。

```text
frontend/
├── index.html
├── style.css
└── script.js
```

## index.html

画面の構造を担当する。

例：

* ヘッダー
* 料金カード
* グラフ表示領域
* サービス別料金表示領域

## style.css

画面のデザインを担当する。

例：

* レイアウト
* カードデザイン
* 文字サイズ
* 余白
* レスポンシブ表示

## script.js

画面上のデータ処理を担当する。

Phase 1-Aでは最初に仮データで画面表示を確認し、その後API Gateway経由でAWSの実データを取得する構成へ変更する。

---

# 7. Phase 1-A 開発順序

Phase 1-Aは以下の順序で開発する。

1. HTML / CSS / JavaScriptの基本ファイルを作成
2. 仮データを使用してダッシュボード画面を作成
3. AWS Cost Explorerの仕組みを理解する
4. LambdaからCost Explorer APIを呼び出す
5. API Gatewayを作成する
6. JavaScriptからAPIを呼び出す
7. 仮データをAWSの実データへ置き換える
8. 動作確認を行う
