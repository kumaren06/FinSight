# 2. プロジェクト概要

FinSightは、AWSを利用する企業・クラウドエンジニア・AWS管理者を対象とした、クラウドコストの可視化・分析支援システムである。

AWS Cost Explorer等から取得した利用料金情報を整理し、Webブラウザ上のダッシュボードに表示することで、AWS環境におけるコスト状況を一目で把握できるようにする。

将来的には、コストの異常検知、不要リソースの検出、自動最適化、生成AIによる分析・改善提案まで機能を拡張する。

---

# 3. 開発背景

クラウドサービスは必要なリソースを柔軟に利用できる一方、利用するAWSサービスやリソースが増加すると、全体のコスト構造を把握しにくくなる。

特にAWSを利用する企業では、

* どのサービスにどれだけ費用が発生しているか
* 今月どの程度の料金になっているか
* 過去と比較して料金が増加しているか
* 想定していないコストが発生していないか

などを継続的に確認する必要がある。

現在はAWS Cost Explorer等を利用して確認できるものの、利用者自身が期間やサービスなどを指定して確認・整理する必要があり、継続的なコスト把握には手間がかかる。

そこで、必要な情報を一つのダッシュボードに集約し、AWSコストの状況を直感的に把握できるシステムを開発する。

---

# 4. 解決する課題

FinSightでは、主に以下の課題を解決する。

## 4.1 AWSコストの内訳が分かりにくい

AWS利用料金が、どのサービスによって発生しているのかを把握しにくい。

## 4.2 意図しないコスト発生に気付きにくい

利用者が想定していなかった料金が発生していても、継続的に確認しなければ気付きにくい。

## 4.3 コスト確認・集計に手間がかかる

AWS利用料金を確認するために、利用者がAWSコンソール上で情報を確認・整理する必要がある。

---

# 5. プロジェクトの目的

FinSightの目的は、AWS利用料金に関する情報を分かりやすく整理し、利用者がAWS環境のコスト状況を短時間で把握できるようにすることである。

Phase 1では、特に以下を実現する。

> 「FinSightの画面を開くだけで、現在のAWSコスト状況とその内訳を把握できる」

---

# 6. 想定利用者

## 6.1 メインターゲット

AWSを利用する中小企業・ベンチャー企業。

## 6.2 想定ユーザー

* クラウドエンジニア
* AWS管理者
* インフラ担当者

将来的には、技術的な知識が少ない管理者・マネージャーでもAWSコストを理解できるシステムへの拡張を想定する。

---

# 7. 想定される現在の運用

利用者はAWS Cost Explorer等を利用して、AWS利用料金を確認する。

基本的な流れは、

1. AWSコンソールへアクセスする
2. Cost Explorerを開く
3. 対象期間を指定する
4. 利用料金を確認する
5. サービスごとの料金を確認する
6. 必要に応じて情報を整理・比較する

という手順になる。

FinSightでは、これらの確認作業の一部をダッシュボード上に集約する。

# 15. 非機能要件

## 15.1 セキュリティ

* AWS認証情報をソースコードへ直接記載しない
* GitHubへ秘密情報をコミットしない
* IAM権限は必要最小限とする
* HTTPSによる通信を基本とする
* APIへの不要な権限付与を避ける

## 15.2 可用性

可能な範囲でAWSマネージドサービス・サーバーレスサービスを利用し、常時稼働するサーバーへの依存を減らす。

## 15.3 保守性

* GitHubによるソースコード管理
* Markdownによるドキュメント管理
* 構成図の保存
* API仕様の明文化
* READMEによる利用方法・構成の説明

## 15.4 拡張性

Phase 2・Phase 3で機能を追加できる構成を意識する。

特に、

* コスト最適化
* 自動化
* AI分析
* 複数アカウント対応

への拡張を想定する。

## 15.5 コスト

個人開発・学習用途であることを考慮し、AWS利用料金を可能な限り抑える。

AWS上で発生するコスト自体もFinSightの学習対象とし、必要に応じてAWS Budgets等を利用して管理する。

# 22. プロジェクトの最終目標

FinSightを単なるAWS料金表示アプリケーションではなく、

> **AWSのコストを「見る」→「理解する」→「改善する」→「AIに支援してもらう」**

というクラウド運用の一連の流れを支援するプラットフォームへ発展させる。

また、開発者自身も本プロジェクトを通じて、

* AWS
* クラウドアーキテクチャ
* Linux
* Web開発
* API
* IaC
* CI/CD
* FinOps
* AI活用
* システム設計
* テスト
* 運用

を段階的に学習し、実際の開発・運用を想定した経験を積むことを目的とする。
